# 日常记账

Python + Streamlit 记账网站。账目保存在 Supabase 的 PostgreSQL 数据库中，网页使用 Python 标准库调用 Supabase REST API，从云端读取流水并生成月度汇总和图表。

## 第一次设置

### 1. 创建 Supabase 账目表

在 Supabase 项目打开 **SQL Editor → New query**，粘贴并运行：

```sql
create table if not exists public.ledger_entries (
  id bigint generated by default as identity primary key,
  kind text not null check (kind in ('收入', '支出')),
  amount_cents bigint not null check (amount_cents > 0),
  category text not null,
  occurred_on date not null default current_date,
  note text not null default '',
  created_at timestamptz not null default now()
);

create index if not exists ledger_entries_occurred_on_idx
  on public.ledger_entries (occurred_on desc, id desc);

alter table public.ledger_entries enable row level security;
grant select, insert, delete on public.ledger_entries to anon, authenticated;
grant usage, select on sequence public.ledger_entries_id_seq to anon, authenticated;

create policy "Public can read ledger entries"
  on public.ledger_entries for select to anon, authenticated
  using (true);

create policy "Public can add ledger entries"
  on public.ledger_entries for insert to anon, authenticated
  with check (true);

create policy "Public can delete ledger entries"
  on public.ledger_entries for delete to anon, authenticated
  using (true);
```

### 2. 在本机配置 Supabase 连接

在项目目录中创建 `.streamlit` 文件夹，再在里面创建 `secrets.toml`。填入项目自己的 URL 和 Publishable key：

```toml
[supabase]
url = "https://你的Project-ID.supabase.co"
key = "你的Publishable-key"
```

Project ID 可用于组成 URL。密钥只保存在自己的电脑上，不要贴到聊天、不要放进 `app.py`，也不要分享 `secrets.toml`。不要使用 `service_role` 或 `secret` key。

**数据访问提醒：**当前按要求不做登录权限。任何能访问网站的人都可以读取、新增和删除这张账目表，因此只适合受控的组内原型，不要放敏感账目。如果要公开部署，应先增加登录和成员权限。

## Windows 启动

安装 Python 3.10 或更高版本后，在 VS Code 打开项目文件夹并打开终端，运行：

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m streamlit run app.py
```

浏览器打开终端显示的网址，通常是 `http://localhost:8501`。以后启动时只需运行最后一条命令。

## 组员使用

每位组员都需要安装 Python、获取项目代码、创建自己的 `.streamlit/secrets.toml`，并安装依赖后运行网站。大家连接同一个 Supabase 项目，因此看到的是同一份云端账本。旧的本地 `ledger.db` 不会自动迁移。
